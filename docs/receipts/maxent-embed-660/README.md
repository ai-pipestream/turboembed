## Red cases

The tests first ran against the corresponding pre-fix paths after the mechanical split. The allocation, label/grouping, and overlap probes were added later and run with their respective checks absent before restoring the fix. These are isolated regression receipts, not a claim that all probes ran against an untouched base checkout.

- `red.log`: six failures for non-finite query values, tiny positive temperature, non-finite multi-label parameters, excess labels, invalid vector columns, and window endpoint overflow.
- `red-maxent.log`: four failures for malformed XML declarations, central directory size, entry disk number, and local-header metadata mismatch.
- `red-allocation.log`: a short centroid payload reserved 4,000,000 bytes from its declared dimension before reporting EOF. The fixed path checks available bytes first.
- `red-vectors.log`: discontinuous span pooling silently included the gap. The fixed path rejects unsupported discontinuous input.
- `red-rows.log`: zero row stride was accepted. Construction now enforces the documented positive stride requirement.
- `red-labels-grouping.log`: duplicate/blank labels and invalid category columns were accepted.
- `red-overlap.log`: an entry payload could overlap the central directory.

Sixteen failing regression tests in total. Ordinary finite centroid scoring keeps its original arithmetic. Tiny-temperature scoring uses a stable fallback; the centroid configuration hash includes a scoring revision. Vector annotator versions advance to 1 for the changed discontinuous-input contract. The TCENT001 wire format is unchanged.
