# SaT on devices against the CPU (#884)

`analysis/sat/tests/device.rs` runs the SaT step on the CPU and on the
device `TURBO_TEST_DEVICE` names, with the same bundle, and holds every
token's boundary probability to the tier's bound of the CPU's (1e-4 at
f32, 1e-2 at f16); tokens the threshold puts on the other side must have
a CPU probability within that bound of it, and are listed. The packed
test reads 36 documents together, so that runs fill, at the bundle's
max_batch and at 3 rows a run, against each document read alone on the
CPU. `tests/speed.rs` alternates a CPU pass with a device pass and gives
the median of each.

Bundles: `testdata/tiny-sat-bundle` (2 layers, width 32) and
`sat-1l-sm` at `00a783439c201b20ee91ee1624dc817f1bf0e578` sealed from
`bundle/recipes/sat-1l-sm.json` with xlm-roberta-base's tokenizer
(#1020; manifest `c3a0dbcc`), named by `TURBO_TEST_SAT_BUNDLE`.

## CUDA: RTX 4080 SUPER

Driver 615.71.09, nvcc 12.4.131, release build, `--features turbo/cuda`.

```
TURBO_TEST_DEVICE=cuda TURBO_TEST_PRECISION=<p> [TURBO_TEST_SAT_BUNDLE=<sat-1l-sm>] \
  cargo test --release --locked -p turbo-sat --features turbo/cuda --test device --test parity -- --nocapture
```

`tests/device.rs`: 3 of 3 pass at `model`, `fastest` and `exact` on
both bundles. Largest probability difference against the CPU:

The packed runs read 284 windows (tiny) and 208 (sat-1l-sm). The four
tiny `fastest` tokens are one token of a text repeated in four
documents, 6.8e-4 under the threshold on the CPU.

`tests/parity.rs` against wtpsplit: at `model` and `exact` all six
pass, with the same Seen figures as the CPU, and the released
checkpoint passes too. A model of limited lookahead is refused on the
device (`turbo::model::runs_band`), which the lookahead test now checks
there. At `fastest` the four tiny-fixture tests and the released one
fail over the 1e-3 allowed against wtpsplit (largest 1.1e-3), as
docs/neural-annotators.md records.

tier named. The GPU was shared with desktop applications (about 26%
busy, no compute jobs), so the ratios carry more weight than the
