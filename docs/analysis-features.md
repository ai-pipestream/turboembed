# Analysis Feature Checklist

This table maps the 200-row Apache OpenNLP 3.0, add-on, and sandbox feature inventory to our Rust analysis architecture (`docs/analysis.md`, #1509, #1510, #1536). It serves as a capability checklist: our crates own their semantics, layer invariants, and binary formats rather than reproducing Java class hierarchies or classical `.bin` models.
