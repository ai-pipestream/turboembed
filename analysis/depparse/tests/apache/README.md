# Current Apache dependency import fixtures

`Generate.java` trains actual Apache parsers on the four unchanged, attributed
UD excerpts in `../data/ud-en.conllu` and `../data/ud-es.conllu` (65 syntactic
words). These small bilingual models test format and prediction compatibility;
they are not pretrained language models or accuracy evidence.

The 23 unmodified dependency, validation and CoNLL-U source classes come from
Apache OpenNLP commit `95695633b580a445617a791f05a02b61b65b3b74`.
They were compiled ahead of support jars from the pinned reference build
`cdf33c653d5d61d5af7d37ffee189a83bd8392ea`, using Temurin 21.0.12.1+1.
This is a current dependency-source oracle with older pinned support libraries,
not a claim that every runtime class comes from current Apache main.

- `linear.bin`: actual maxent trainer, five iterations, cutoff 1, one thread.
- `apache.bin`: embedding width 3, hidden width 5, three epochs, batch 4,
  cutoff 1, dropout 0, seed 17; other settings use Apache defaults.
- `apache-refined.bin`: the preceding model with one real early-update
  refinement epoch and beam 4. Its manifest records that default beam.
- TSVs: every predicted head and complete relation label on the four inputs.
  Neural results cover greedy and beam 4, 130 arcs per model. The linear
  result covers 65 arcs. Root heads are -1 and all other heads are zero-based.
- `native-v1.bin`: the existing legacy `../feedforward/data/plain.bin`
  loaded and serialized by TurboEmbed commit
  `75160eceda1101837cb0dbfe23b435b591b9ca8b` before the version 2 writer.
  It preserves the original version 1 compatibility boundary. Its source
  fixture and training provenance remain documented in that directory.

Set `OPENNLP_SOURCE` and `OPENNLP_CP`, then run `regenerate.sh` from the
repository root. Regeneration compares every prediction and the actual model
artifact bytes. Apache ZIP timestamps and manifest generation dates can vary,
so the enclosing ZIP bytes are not the reproducibility assertion. The frozen
native v1 fixture is not regenerated by a newer native writer. Java is only
needed to regenerate reference fixtures; normal loading, conversion, inference
and the test suite do not need Java or Python.

The UD excerpts, their derived model fixtures and reference predictions retain
CC BY-SA 4.0 and the full attribution/license notes in `../data/README.md`.
Underlying text rights remain as documented there. Apache OpenNLP code is
Apache-2.0. The legacy-derived native v1 fixture retains its original license.
