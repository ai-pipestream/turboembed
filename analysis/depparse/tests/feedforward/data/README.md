# Neural dependency reference fixtures

These fixtures were generated by `NeuralReference.java` using the unmodified
OpenNLP sources at commit `cdf33c653d5d61d5af7d37ffee189a83bd8392ea` in
ai-pipestream/opennlp. Java compiler/runtime: OpenJDK GraalVM CE 25.0.3,
x86_64. Runtime support jars: OpenNLP 3.0.0-SNAPSHOT and slf4j 2.0.17.

`plain.bin` and `dropout.bin` are the Java trainer's complete raw model
streams. The matching TSV files contain all oracle contexts, feature IDs,
forward scores, and greedy/beam-4 results for the fixture sentence.
`normalize.tsv` records Java word normalization, including final sigma,
U+0130, supplementary characters and reserved symbols.

Training settings: embedding width 3, hidden width 5, three epochs,
batch size 4, learning rate 0.02, word cutoff 1, seed 17. The plain model
uses dropout/L2 0; the dropout model uses dropout 0.3 and L2 0.001. The
synthetic corpus is in the generator. Rust compares the vocabulary and
transition inventory exactly and every learned parameter and forward score
with relative tolerance 1e-6 and scale floor 1e-8. Repeated Rust runs must
serialize identically. Loading and reserializing the Java models must be
byte-exact. These tiny fixtures test compatibility, not language accuracy.

Set `OPENNLP_SOURCE` to a checkout at the pinned commit and `OPENNLP_CP` to
compatible dependency jars. Run this directory's `regenerate.sh` from the
repository root. It reads sources from Git, compiles them before the jars,
generates files under `target/feedforward-reference`, and compares all five
outputs with the committed fixtures. Tests require neither Java nor network
access. No source checkout is modified.

The neural algorithm and compatibility behavior are reimplemented from
Apache OpenNLP under Apache-2.0. The fixture sentences are synthetic.
