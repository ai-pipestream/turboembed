# Potion vectors

`potion-32-159.f32` contains embedding table rows 32 through 159 inclusive
from minishlab/potion-base-8M, commit bf8b056651a2c21b8d2565580b8569da283cab23.

not generated vectors. Source model.safetensors SHA-256:
