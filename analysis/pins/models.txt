# Every model a test, gate, evaluation or record loads, pinned by the
# SHA-256 of its bytes, written as its key in the content-addressed model
# store of #1613: blobs/sha256/<64 hex>. One pin per line: the key, the
# kind, and a name for people (for a bundle seen only in a record, the
# model id and the first record that names it).
#
# Kinds, and the bytes each digest is over:
#   bundle   a bundle's manifest.json, which names every file of the
#            bundle with its size and SHA-256; Bundle::open and every
#            verified read check those, so the manifest pin pins them all
#   package  a GLiNER, GLiREL or DeBERTa package's own manifest
#            (gliner.json, glirel.json, deberta.json), which binds its
#            files' digests the same way. A model directory inside a
#            bundle or package (a GLiREL package's encoder/) must be bound
#            too: named by digest in the outer manifest (gliner.json names
#            encoder/deberta.json) or pinned by its own line here
#   file     one model file (an OpenNLP model, a head, a checkpoint file)
#   tree     a directory with no manifest: the SHA-256 of its listing, one
#            line "<sha256>  <relative path>\n" per regular file, in
#            byte order of the path (turbo_pins::digest)
#
# Also pinned, without a line here: every file of the zoo index
# (analysis/zoo/index/zoo.json) and every score-only reference model in
# analysis/train-recipes/*-references.txt, which pin their files already,
# except a retired model's (OpenNLP 1.5 and 2.5 models, #1509).
#
# A test that loads a model from a path it is given goes through
# turbo_pins::require, which refuses a model whose digest is not here;
# `cargo run -p turbo-pins -- <path>` prints the line to add, which goes
# in with the record or test that first uses the model.
