# turbo-parser

Constituency parse trees, Penn Treebank bracket I/O, and language head rules (`opennlp.tools.parser`).

## Components

- `parse`:
  - `Parse` (`opennlp.tools.parser.Parse`): constituency tree node with shared `Arc<str>` sentence text, UTF-8 byte `Span` offsets, head constituent tracking, derivation tracking, tree mutation (`insert`, `add`, `adjoin`, `adjoin_root`, `expand_top_node`, `prune_parse`, `fix_possessives`, `add_names`), and node queries (`tag_nodes`, `token_nodes`, `initial_chunks`, `tag_sequence_prob`).
  - `Parse::parse` and `Parse::parse_with_options`: single-pass cursor scanner for Penn Treebank bracketed trees (`OPENNLP-XXXX-treebank-scanner`), with malformed tree validation (reporting UTF-16 input offsets), outer `((S ...))` file wrapper support, optional non-numeric function tag retention, and `-NONE-` trace handling via `GapLabeler`.
  - `Parse::show` and `Parse::to_string_penn_treebank`: Penn Treebank bracket serialization with bracket token escaping (`encode_token`, `decode_token`).
  - `space_untokenized_parens` (`ParserTool.spaceUntokenizedParens`, `OPENNLP-XXXX-parser-brackets`): single-pass forward scanner separating round and curly brackets from adjacent non-whitespace characters without regular expressions.
- `head_rules`:
  - `HeadRules` (`opennlp.tools.parser.HeadRules`) and `GapLabeler` (`opennlp.tools.parser.GapLabeler`).
  - `EnglishHeadRules` (`opennlp.tools.parser.lang.en.HeadRules`): Collins/Magerman English head rules with `NP`/`NX` priority passes, subject and object trace extraction gap labeling, and rule file reader/serializer.
  - `AncoraSpanishHeadRules` (`opennlp.tools.parser.lang.es.AncoraSpanishHeadRules`, `OPENNLP-XXXX-ancora-tag-rules`): AnCora Spanish head rules using a 62-state `u64` bitmask automaton (`TagPattern`) with zero backtracking or allocation during matching, supporting both `# opennlp-ancora-head-rules 2` and legacy headerless rule files.
- `stream`:
  - `ParseSampleStream` (`opennlp.tools.parser.ParseSampleStream`), `ParserPosSample` (`opennlp.tools.parser.PosSampleStream`), and `ParserChunkSample` (`opennlp.tools.parser.ChunkSampleStream`).

## Test vectors

`tests/parser_tests.rs` compares `Parse`, `EnglishHeadRules`, `AncoraSpanishHeadRules`, `ParserPosSample`, and `ParserChunkSample` against JVM reference outputs in `tests/vectors/parse_vectors.tsv`, generated by `java/Vectors.java` inside the pinned Temurin 21 container (`eclipse-temurin:21-jdk@sha256:3e3c176ffed168beb42c607be9bc1639b466cf00261a0fb04425562c9d0c5c2b`).
