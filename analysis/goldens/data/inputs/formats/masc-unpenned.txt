# A MASC-format corpus written for the turbo-formats tests: hand-written text
# and stand-off annotation in the layout of MASC 3.0 (GrAF). Not MASC data.
# No document has Penn tokens or named entities, so the part-of-speech,
# token and name streams' constructors find no document to read.

@@ file plain.hdr
<?xml version="1.0" encoding="UTF-8"?>
<documentHeader xmlns="http://www.xces.org/ns/GrAF/1.0/" docId="TEST" version="1.0.4">
  <profileDesc>
    <primaryData f.id="f.text" loc="plain.txt"/>
    <annotations>
      <annotation loc="plain-s.xml" f.id="f.s">annotation</annotation>
      <annotation loc="plain-seg.xml" f.id="f.seg">annotation</annotation>
    </annotations>
  </profileDesc>
</documentHeader>

@@ end

No tags here. None at all.
