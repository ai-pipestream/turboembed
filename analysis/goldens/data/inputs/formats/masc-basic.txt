# A MASC-format corpus written for the turbo-formats tests: hand-written text
# and stand-off annotation in the layout of MASC 3.0 (GrAF). Not MASC data.
# Three documents: one with Penn tags and named entities, one without named entities, one with neither.

</documentHeader>
